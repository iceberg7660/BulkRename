# 批量重命名工具（macOS 版）

基于 PySide6（Qt6）的桌面 GUI 程序，读取 Excel 名单，根据名单中某列的值匹配文件夹中的文件名，按用户指定的字段组成规则批量重命名文件。由 Windows 版（Python + PyQt5）移植而来，Windows 版见[仓库根目录](../)。

**不想装 Python？** 到 [Releases](https://github.com/iceberg7660/BulkRename/releases) 下载 `BulkRename-mac.app.zip`，解压后把 `批量重命名工具.app` 拖入「应用程序」即可使用。

## 功能特点

- **任意多列支持**：不限于学号+姓名两列，Excel 有多少列就支持多少列
- **智能表头识别**：自动检测第一行是否为表头，可通过复选框手动纠正
- **动态列名**：有表头时读取表头作为字段名，无表头时自动生成"列1""列2"…
- **自定义字段**：可动态添加最多 5 个自定义字段（如"作业名"），每个字段有名称和值
- **灵活匹配**：可选择任意列作为匹配依据，程序自动选择含中文最多的列作为默认匹配列
- **动态文件名组成**：组合框数量自动跟随字段数变化，选项实时刷新
- **实时预览**：修改任意选项后立即显示最终文件名预览
- **匹配列重复检测**：导入名单或切换匹配依据列后自动检测该列重复值并弹窗提醒；重命名时仅第一个重名行参与，其余跳过
- **结果报告**：重命名完成后弹窗汇总成功数、失败数（重命名出错 / 未匹配到文件 / 因重复跳过）及各项原因明细

## 运行环境

- macOS（Apple Silicon，已在 Python 3.13 下验证）
- Python 3.9+，依赖：`openpyxl`、`PySide6-Essentials`

```bash
python3 -m pip install -r requirements.txt
```

## 运行

```bash
python3 main.py
```

## 打包成 .app

```bash
bash build_app.sh
```

- 产物：`dist/批量重命名工具.app`（约 72 MB），双击即可运行，顶部菜单栏应用名正常显示
- 体积控制：打包时排除被连带分析进来但本项目用不到的包（numpy / PIL / lxml / tkinter / charset_normalizer，约省 55 MB；已验证屏蔽后 openpyxl 照常读写名单），并删除 Qt 自带语言文件 `*.qm`（6.7 MB，界面文案内置在代码中，删除后不影响使用）
- 「使用预设名单」在打包版中查找 **.app 同目录**的 `名单.xlsx`（打包脚本会自动复制一份到 `dist/`）
- 产物为 ad-hoc 签名：发给别人时首次打开需右键 →「打开」，或执行 `xattr -cr 批量重命名工具.app`；本机使用无此问题

## 使用方法

1. 选择名单文件（Excel 格式，支持 `.xlsx`）
2. 程序自动识别第一行是否为表头，可通过复选框纠正
3. 选择匹配依据列（用于在文件名中定位原文件）
4. 选择需要重命名文件的文件夹
5. 可选：输入新的文件夹名字
6. 可选：点击「＋」添加自定义字段（最多 5 个），每个字段包含名称和值
7. 选择最终文件名的组成顺序
8. 点击「重命名」按钮开始重命名

### 匹配原理

将名单匹配依据列的值与文件名字符串比对，文件名中包含该值即视为匹配。例如：名单中姓名为"张三"，文件夹中有"张三的作业.docx"，则匹配成功。

### 匹配列重复处理

若匹配依据列中存在重复值（如两行的姓名都是"张三"），导入名单或切换匹配列时会弹窗提醒。重命名时仅名单中最先出现的一行参与重命名，其余重复行将被跳过（不做处理），重命名结束后的结果弹窗会列出哪个重名行成功（含原名和现名）、哪些被跳过。

### 重命名规则

最终文件名 = 用户在 Step5 中各组合框所选字段的值按顺序拼接，保留原文件后缀名。

## 与 Windows 版的差异

- GUI 框架由 PyQt5（Qt5）换为 **PySide6（Qt6）**：PyQt5 对 Python 3.13 和新版 macOS 的支持已过时，PySide6 是 Qt 官方绑定，API 与 PyQt5 基本一致
- 重命名完成后自动在 **Finder** 中打开文件夹（Windows 版调用 `os.startfile`，macOS 无此 API）
- 文件名非法字符处理改为 **macOS 规则**：仅 `/` 和 `:` 会替换为下划线（Windows 版替换 `\ / : * ? " < > |`，其余字符在 macOS 均合法）
- 名单文件仅支持 `.xlsx`：openpyxl 本就不支持旧版 `.xls`，文件选择对话框已相应收紧，避免误导
- 文件夹重命名适配了 POSIX 语义：目标文件夹已存在且非空时给出提示并继续（Windows 上对应 `FileExistsError`，macOS 上是 `ENOTEMPTY`），不再中断整个流程
- 「简介 / Qt6介绍」菜单项归入「帮助」菜单（macOS 菜单栏由系统统一管理）
- 修复了一个原版就存在的联动 bug：表头复选框的确认弹窗选「No」后，勾选状态会回弹到改动前（原版会停留在新状态，导致界面与实际解析数据不一致）

## 预设名单

程序支持使用脚本同目录下的 `名单.xlsx` 作为预设名单文件。该文件不会被提交到版本控制。

## 注意事项
